# 组件规范

## 按钮 Button
| 类型 | 高度 | 内边距 | 背景 | 文字 | 描边 | 使用场景 |
|---|---|---|---|---|---|---|
| 主按钮 | 32 | 0 16 | `#0F3B5D` | `#fff` | 同色 | 保存、提交、确认 |
| 次按钮 | 32 | 0 16 | `#2878B5` | `#fff` | 同色 | 查询、上传 |
| 幽灵按钮 | 32 | 0 16 | `#fff` | `#0F3B5D` | `#0F3B5D` | 重置、取消 |
| 危险按钮 | 32 | 0 16 | `#fff` | `#B22B31` | `#B22B31` | 驳回、删除（二次确认） |
| 小号 | 28 | 0 12 | 同上 | | | 表格行内操作 |
圆角 6px，字号 13px；禁用态 45% 透明度；行内最多「查看 + 2 个高频操作」，其余收进「更多」。

## 表单 Form
- 标签在上或左对齐 100–120px，必填项前置红色 `*`
- 输入框 32px 高（普通）/ 42px（登录页），圆角 6px，描边 `#DCE6EE`
- 聚焦：描边 `#2878B5` + `box-shadow 0 0 0 3px rgba(40,120,181,.12)`
- 下拉宽度 200px（`select.w200`），长文本可 240px，不超过 240px
- 复杂表单支持「保存草稿」；关闭前检测未保存内容
- 校验：必填、长度、起止时间顺序、唯一性由后端二次校验，错误统一 toast

## 表格 Table
- 表头背景 `#F8FBFD`，字号 12.5px，颜色 `#5F7484`，`white-space: nowrap`
- 行高 44px（`td` padding 11/12），行线 `#EEF3F7`，hover `#F7FBFE`
- 列宽不写死，按内容自适应；编号/状态/日期/操作列单行不换行
- 状态列用文字标签，不使用纯色圆点
- 分页在表格下方右对齐：总数、页码、每页条数（10/20/50），切换筛选回第 1 页
- 空状态：说明原因 + 下一步（"当前筛选条件下无记录，清空筛选或新建教研成果"）
- 加载超过 300ms 显示局部骨架，不整页白屏

## 卡片 Card
- 背景 `#fff`，1px `#DCE6EE`，圆角 8px，内边距 18/20px
- 标题 16px/600，右侧可放说明或操作（12px `#5F7484`）
- 卡片之间 16px 垂直间距

## 标签 Tag
内边距 2/9px，圆角 4px，字号 12px，行高 18px：
`t-g` 成功（#E6F3EC/#1F7653）、`t-b` 进行中（#E8F1F9/#0F3B5D）、
`t-y` 待处理（#FBF1E2/#8A5A12）、`t-r` 异常（#FAE9EA/#B22B31）、`t-n` 中性（#EEF2F5/#5F7484）。

## 弹窗与抽屉 Dialog / Drawer
- 审批、流转、评审统一用右侧抽屉（宽 420px），抽屉内固定展示单据编号、状态、责任人摘要
- 危险操作二次确认文案包含业务编号与影响范围
- 遮罩 `rgba(15,59,93,.35)`，ESC 可关闭，未保存内容需确认

## 分页 Pagination
默认每页 10，可切 20/50；按钮 28px，当前页用主色加粗；显示"共 N 条"。

## 时间轴 Timeline
左侧 1px 竖线 + 9px 圆点（辅助色 + 白色描边），每条含动作、操作人、时间（`yyyy-MM-dd HH:mm:ss`），
事件只读，不可由普通用户修改。

## KPI 指标卡
白底描边，标签 12.5px 灰色，数值 24px/600 主色，底部补充说明 11.5px 灰色；6 列栅格。

## 空状态 Empty
48px 线性图标 + 说明文案 + 主按钮（如「新建教研活动」），居中，上下留白 40px。
