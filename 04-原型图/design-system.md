# 视觉规范 · 教师教研活动与成果管理系统

## 设计方向
"运动钴蓝" 专业业务系统风格：高数据可读性、操作效率优先、状态可辨识。
不使用巨幅英文口号、装饰光效、悬浮球、大面积插画；圆角 6–8px，阴影只用于抽屉与弹窗。

## 色彩
| 用途 | 色值 | 说明 |
|---|---|---|
| 主色 | `#0F3B5D` | 顶部栏、侧边栏、主按钮、关键数字 |
| 辅助色 | `#2878B5` | 次级按钮、筛选选中、普通图表系列 |
| 强调色 | `#245A7A` | 链接、信息提示、对比系列 |
| 页面背景 | `#F4F8FB` | 内容区背景，卡片为白色 |
| 成功 | `#1F7653` | 已归档、已通过、已认定 |
| 警告 | `#8A5A12` / `#FBF1E2` | 报名中、待审批、待补录 |
| 危险 | `#B22B31` | 退回、异常、删除确认（仅小面积） |
| 分隔线 | `#DCE6EE` | 表格行线、卡片描边 |
| 正文 / 次要文字 | `#1B2B36` / `#5F7484` | |

状态不得只用颜色表达，必须同时出现中文标签。

## 字体阶梯
| 层级 | 字号 / 行高 | 用途 |
|---|---|---|
| H1 | 34 / 1.35 | 登录页主标题 |
| H2 | 22 / 1.4 | 页面标题 |
| H3 | 18 / 1.4 | 卡片标题、详情标题 |
| 卡片标题 | 16 / 1.4 600 | `h2.tt` |
| 正文 | 14 / 1.6 | 表格、表单 |
| 辅助 | 12.5–13 / 1.5 | 说明、标签 |
| 指标数字 | 24 600 | KPI，等宽数字 `tabular-nums` |

字体族：`-apple-system, "PingFang SC", "Microsoft YaHei", sans-serif`；数字列启用 `font-variant-numeric: tabular-nums`。

## 布局尺寸
- 侧边栏 220px（折叠 64px），顶部栏 56px，内容区 padding 24px
- 内容区最大宽度自适应，表格允许横向滚动
- KPI 栅格：桌面 6 列 / 平板 3 列 / 手机 1 列
- 图表区两列栅格，单图高度 210px，首页 6 指标 + 6 图控在一屏（1440×900 无纵向滚动）
- 表单标签 100–120px，单列输入 360–520px，筛选下拉 180–240px
- 卡片内边距 18/20px，卡片间距 16px

## 圆角与阴影
- 卡片 8px，按钮/输入框 6px，标签 4px，头像 50%
- 阴影仅用于右侧抽屉：`-8px 0 24px rgba(15,59,93,.12)`；卡片只用 1px 描边

## 图表配色
主色 #0F3B5D → 辅助 #2878B5 → 强调 #245A7A → 中性 #9AAEBE，
同含义跨页面固定：活动=蓝、成果=青、学时=深蓝、异常=暗红。

## 图标
`icons.svg` 内联 symbol 集，24×24 线性图标，线宽 1.8，颜色继承 `currentColor`，侧边栏图标透明度 0.75。
